# 公开源码维护规则

公开分支只维护可共享源码、合成样本、依赖清单、测试与通用文档。

本次公开准备采用固定文件清单，不是对完整私有目录简单删除几个文件。未纳入：设备／服务器地址和 SSH 别名、账户凭据、原始诊断／相机记录、现场标定、历史交接与工单、完整控制器、第三方 SDK／模型／网格、实验输出及原有 Git 历史。

合成关节输入由固定数列生成，没有使用真实关节观测值。控制片段经 AST 抽取，保持所测函数逻辑；完整控制程序和入口不随片段发布。公开回归覆盖的是这些片段，不能把结果扩展为私有完整控制程序的验收结论。

后续通用库修改在 `src/x2/` 开发并走分支／PR；真实机器配置和实验记录保留在仓库之外。添加新文件时同时检查 `config/baseline-files.json`、资源清单和公开内容边界。测试样本变更需要审查来源和哈希；不能只改哈希让测试变绿。

本版本仅为离线开发基线，不是可运行真机抓取的软件发行版。依赖和安装步骤见 README。第三方依赖、SDK、模型的获取及使用遵循其各自条款；本仓库未擅自添加覆盖第三方资产的许可证。
